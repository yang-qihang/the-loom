## 1. 目标与边界

关卡页「世界方位」示意卡要让人第一眼认出**这一关的时段与天气**：黎明薄云、午后干晴、正午雨、
黄昏落日、初夜冷星。只做像素块天空，不做写实渲染。

- **只画示意**：它不是真实世界截图；真实场景仍以「我的世界」窗口为准（卡片说明保持原句）。
- **配置与渲染分离**：天空数据在 `apps/studio/src/components/scene-sky/`（`types.ts` 契约，
  `act1/2/3.ts` 由各 Act 负责人维护，`index.ts` 聚合）。集成层只读 `skyFor(levelId)`，
  **不要在 SceneIllustration 里写死某一关的云量或颜色**。
- **不做的事**：不碰引擎、服务端、`content/levels/**`、`packages/**`；不在关卡页加圆角卡片或新入口。

## 2. 坐标与绘制带

`viewBox = 0 0 360 210`，固定分段：

| 屏幕带 | y 范围 | 用途 |
| --- | --- | --- |
| 标题带 | 0–40 | 关卡名、`periodLabel · weatherLabel` 文案；云和日月都不放这里 |
| 天空带 | 40–100 | 云、日/月、远山、星点、雨线 |
| 地平线 | 100–104 | 6px 过渡色，天空落到地面 |
| 地面带 | 104–210 | 像素地面/小径、关卡目标标注、灰崽与「你」 |

SkyProfile 里的 `clouds[].y`、`orb.y` 约定按 **40–168 的设计带**书写（接近 168 表示贴地低云/落日）；
集成层用 `mapSkyY()` 线性映射到屏幕的 40–100 天空带。这样 Act 配置可以放心写「低空云」，
渲染端永远不会把云画到地面目标上，也不会压到标题。

## 3. 天空构件怎么画

### 3.1 天空两段色

`skyTop` 画 0–56，`skyBottom` 画 56–100，交界处不加渐变、不加噪点：两段纯色 = 像素风。
时段差异全部来自配置里的天空色，不在渲染层按关卡名 switch。

### 3.2 云：一个 SkyCloud 拆成一朵像素云

配置只给一朵云的包围盒（`x/y/w/h/opacity/kind`），渲染层负责把它变成「云」：

- 阶梯状 5 块：底部阴影条 → 主体条 → 左上亮块 → 中上亮块 → 右侧主体块；
- 加 3 个固定种子的小凸块，避免每朵云都是同一块矩形；
- 颜色由 `skyTop/skyBottom` 混出：亮边向米白混，暗边向石灰褐混；
- `kind: "rain"` 的云换成更暗的雨天色，并在云底加 3 条雨帘短块；
- 同一关的云块位置由 `levelId` 固定种子决定，**每次渲染完全一致**，不会闪。

### 3.3 日/月

- 只用阶梯矩形拼圆盘（7 行宽度变化），外圈加深色轮廓，避免在暖色天空上看不清；
- 配置 `orb.color` 偏暖（红分量明显高于蓝）→ 太阳，画 4 段像素光芒；
- 偏灰冷（红蓝差 < 30）→ 月亮，不画光芒；
- 雨天不画日/月（云层遮住），与 `rain > 0` 联动。

### 3.4 雨、星、远山

- 雨：`rain` 是雨线密度基数，渲染成远/中/近三层（长度 4/7/11，颜色由浅到实），
  从天空一直落到地面带；**雨线画在目标标注之前**，文字始终在最上层。
- 星：只在天顶很暗（`luma(skyTop) < 0.18`）且无雨时出现；30 颗 1–2px 方点，
  且避开标题带（x 90–270 / y 13–35）不留噪点压字。
- 远山：地平线上两条连续的阶梯剪影（远层偏石灰褐、近层偏苔绿），只提供纵深，不抢色。

### 3.5 地面与小径

地面是土褐/石灰的纯色分层；小径用竖向 8px 一段的土色方块拼（不做曲线、不做圆头线帽）。
目标标注与灰崽/「你」的坐标保持原数据，只把人物造型从圆形改成像素直角，名字仍在脚下。

## 4. 配色规则（60 / 30 / 10）

- **60%**：天空两段 + 地面主色，全部自然材质色（灰蓝、暖赭、石灰、土褐、苔绿）；
- **30%**：云、远山、地面分层、目标方块，仍是自然材质色；
- **≤10%**：日/月、最亮的云边、雨线、目标描边等点缀；
- 禁用：荧光绿/紫、粉草地、霓虹红蓝对撞、彩虹羊毛、彩色棋盘墙、渐变塑料、圆角、文字阴影；
- 每个颜色必须有理由：木=木色、石=石灰、水=蓝、麦=金、火/日=暖橙。宁可朴素，不要脏的丰富。

## 5. 文案与控件

- 时段/天气只用中文短语（`periodLabel`/`weatherLabel`），例如「黄昏 · 薄云」「正午 · 雨」；
- 关卡页标题栏在关卡名右边加 `.sky-chip` 小签（像素直角、无圆角），窄屏（<1100px）隐藏，
  保证同排「返回 / 标题 / 重置 / 世界标注 / 织典 / 模式 / 状态」不挤；
- 卡片内的说明句 = `时段 · 天气：note` + 原有「真实世界在我的世界窗口里」；
- 目标标注、灰崽/「你」名签的字号与字色沿用原值（浅米色 `#d8c8a8`），不得被云、雨、人物挡住；
- 标题与注脚不允许文字阴影，靠纯色对比与布局留白保证可读。
