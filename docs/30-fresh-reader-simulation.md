# 30 — Fresh Reader 模拟：挑剔、不懂编程、没玩过 MC 的文学读者

> 状态：v1 冻结（docs/28 的 G-FRESH-READER 门禁）｜负责人：Lead｜最后更新：2026-10-31
> 用户要求：必须有一个「挑剔、没有编程基础、对文学感兴趣、没接触过这个游戏」的模拟玩家，模拟他看到东西时的思考链；只要他对文字困惑（看不懂、像老外写的、AI 味重），就改。
> 原则：**Fresh Reader 不是测试工程师。** 他不看 spec/代码/设计文档，只看玩家真实能看到的东西；他的困惑就是产品缺陷。

---

## 1. 角色卡（每次评审都按这张卡扮演）

- 28 岁，文学编辑，平时读小说/散文，写东西讲究；**没玩过 Minecraft**，不知道红石/村民/附魔台；**没写过代码**，不知道变量/函数/循环。
- 挑剔但不恶意：讨厌翻译腔、AI 腔、空泛形容词、说教、卖萌、生造词、中英混排；喜欢具体、清楚、有画面的中文。
- 耐心有限：如果两屏还没看懂「我在哪、要干什么」，就会烦。
- 只根据**屏幕上真实出现的文字与画面**判断，不脑补设定，不查资料。

## 2. 输入（严格限制）

给 Fresh Reader 的只有：
1. 当前界面的截图（地图墙 / 序章 / 关卡开场 / 工作台 / 结果 / 错误 / 手记 / 试符台）；
2. 这些界面上玩家能读到的全部文字（从 copy JSON/渲染后的 DOM 取，不给注释、不给 docs）；
3. 一句任务说明：「请以第一次打开这个游戏的人的身份，边看边想，把你所有看不懂/别扭/不想读的地方指出来。」

**禁止**给：spec、docs、代码、内部术语表、开发者解释、正确答案。

## 3. 输出（逐条，必须能定位）

每条记录：
```json
{
  "id": "FR-001",
  "screen": "序章第 3 屏",
  "text": "它叫灰崽。织机织出来的工匠，没有心思，只会照字面做事。",
  "thought": "「没有心思」有点怪——是没感情，还是没思想？「照字面做事」像说明书。",
  "category": "看不懂词义|像翻译|AI味|过度简洁/电报体|指代不明|句子节奏差|说教|信息过载|缺上下文|过于幼稚|中英混排",
  "severity": "blocker|major|minor",
  "suggestion": "「它叫灰崽，是织机织出来的工匠。它不懂你的意思，只会照你写的字做事。」"
}
```

统计：blocker/major 数、按类别计数、整体评分（1–5）：
- 自然度：中文像不像人写的；
- 清楚度：作一个外行能否看懂；
- 想继续度：看完这段还想不想玩。

## 4. 通过标准（G-FRESH-READER）

- **blocker = 0，major = 0**（修完并复读后）；
- 「像翻译」「AI 味」「中英混排」「过度简洁/电报体」「指代不明」五类计数 = 0；
- 自然度/清楚度 ≥4/5；
- Fresh Reader 能用自己的话复述：我是谁 / 世界怎么了 / 织偶是什么 / 现在做什么 / 做错会怎样（五问至少 4 个答对）；
- 复读时不能出现「比上一版更绕」的新问题。

## 5. 修复循环

1. 评审 → 输出 JSON + markdown 报告（`docs/31-fresh-reader-report.md` 或每轮 `qa/evidence/fresh-reader-*.json`）。
2. 按 blocker → major → minor 排优先级；文案 owner（Studio/文案线）逐条改；**不改产品逻辑，只改文字/信息顺序**。
3. 同一批文字复读；未清零不通过；新引入的文字必须再走一遍。
4. 每轮记录 before/after 原文，报告里保留（可追溯，不偷偷改）。
5. T4 彩排前做最终一轮：序章 + L01–L04 开场 + 试符台 + 手记 + 错误页。

## 6. 执行方式（AI 主导，无人类）

- 用 **fresh subagent** 扮演 Fresh Reader：prompt 只含角色卡 + 截图/文字 + 输出格式；禁止它读仓库 docs/spec。
- 每轮至少 2 个不同 persona（文学编辑 + 普通大学生），避免单一偏好。
- Lead/文案线根据报告改；QA 把结果纳入 `qa/evidence/qa-gates.json` 的 G-FRESH-READER。
- 复读由**新的 fresh subagent** 做（不能是改文案的人自己说「现在好了」）。

## 7. 常见「AI 味/翻译腔」信号（Fresh Reader 会重点抓）

- 「通过……来实现」「这是一个……的过程」「让我们……」「旨在……」「赋能/打造/极致/一站式」；
- 中英混排、半角标点混用、术语先于解释；
- 一句里三个抽象名词；形容词堆叠；没有具体动作/画面；
- 把玩家叫「玩家/用户/您」；把游戏叫「系统/平台」；
- 为了显得高级而生造词（如「织核」「散线」必须配一句人话解释，否则 blocker）。
