### 1.3 目标与挑战句式

- 目标 = 「做什么 + 做到什么程度」，≤20 字/条、每关 ≤3 条；目标里不放 API 名。
- 加练 = 标题（≤8 字）+ 目标（≤20 字）+ 说明（≤45 字）；可跳过、不计星、不影响通关。
- 正例：「让灰崽把 1 到 3 号路灯一盏一盏点亮」「你写的同一个程序要连过三个夜晚」「种子只剩六成也种满田」。
- **完整句（docs/20 §3b2）**：目标/任务/错误/按钮说明必须有主语、指代清楚、读出声像人说话；宁可多写 5–10 字，也不要「点灯。回村。」「照抄第一盏…」「过去→收→回来」这类电报体或箭头链。

### 1.4 错误三要素

- 模板：第 N 行 + 哪里错 + 改成什么，≤2 句；不出现异常名、堆栈、英文状态词。
- 例：「第 5 行把数量固定住了，后面加不上去；你把行首的 `const` 改成 `let`，后面的数字留着别动。」（代码引用反引号，同句说明含义）

### 1.5 教练语气（艾拉）

- 短句、具体、不吓唬人、不空夸；一次只说一件事；允许引用代码位置，不贴完整代码。
- 不出现「我们」「让我们」「玩家/用户/您」；不堆感叹号。
