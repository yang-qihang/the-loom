# 19 — 美术指导（Art Direction）：把「上限」变成「稳定好看」

> 状态：v1（D41）｜负责人：Lead｜最后更新：2026-10-31
> 触发：用户问「哪一个设定对应的场景做出来更美观」；对照方案（single-village）在包装/统一性上更强。
> 结论：**保留「织界」三幕叙事与多场景上限，但采用「一张主地图 + 三场所密度 + 固定机位 + 调色/光照脚本」的美术纪律**；不改成单一村庄小地图，也不放任 10 个场景各自为战。

---

## 1. 先回答「哪个更美观」

| 比较口径 | 更优 | 原因 |
|---|---|---|
| **单场景密度与统一性**（4 天内稳定好看） | 对方的「溪木驿」（单村/三场所/手工摆放/固定视线） | 一张 80×64 的地图，目标物、动线、镜头都可控；每平方米的美术投入高；截图容易「像成品」 |
| **视觉上限/多样性/高光** | 我们的「织界」（黄昏灯河、麦田、夜巡、悦灵、破晓、峡谷合龙桥） | 多场景 + 自然世界 + 时间变化 + 大小对比，能做出更强的情绪曲线与「值得记住的瞬间」 |
| **风险** | 我们的方案 | 场景多、Act III 需要大体量演出，4 天内若无美术纪律会「每个都半成品」 |
| **结论** | **保留我们的设定，吸收对方的纪律** | 上限高 + 下限稳；见 §2 的 6 条硬规则 |

> 对方最值得学的一点：**它先设计「看什么、从哪看、光怎么打」，再设计任务**；我们之前是「任务先行、演出后补」。这份文档就是把这个顺序掰回来。

## 2. 六条硬规则（所有关卡必须遵守）

1. **一张主地图，不跳 biome**：所有 Act 都在同一片「灰岩村 + 周边」区域内（半径 ≤ 300 格）：村庄中心、西侧农田、东侧工坊、北侧峡谷/旧矿、村下大织机遗迹。远距离换景只在过场用 title/黑场，不做跨生态群系旅行。
2. **每个场景 = 一个「三分钟可看完」的舞台**：一个主焦点物体 + 一条引导动线 + 两个前景/背景层次；禁止在可视范围内堆三个以上互相抢注意力的目标。
3. **固定机位 + 固定时刻**：每关定义 1 个玩家主要观察位（playerBeat/开场传送点）+ 3 个截图机位；时间/天气由场景锁定（不随玩家进服变化），截图用固定 FOV/时间/天气。
4. **每 Act 一套调色/光照脚本**（见 §3）：方块 palette、光照色、粒子色、UI 主题三处一致；禁止一关一个风格。
5. **密度靠「便宜的美知道具」**，不靠新建筑：灯笼、营火/烟、旗帜/横幅、花盆、栅栏、苔藓/藤蔓、堆肥桶、物品展示框、蜂巢、地毯、楼梯细节、告示牌；每关至少 8 个「非功能装饰点」。
6. **不追求手工大建筑**：桥/织机/工坊都用已验证的参数化 builder（docs/07 §6 的 28 个）+ 少量局部手修补；单场景手工摆放预算 ≤ 2 小时 agent 时间，超过就降级形状。

## 5b. 排版对齐（与 docs/20 §3b3 一致）

- 页面主标题、幕标题、关卡标题、面板标题**水平居中**；正文左对齐。
- 同级标题同一字号/字重/颜色；标题栏高度与内边距统一。
- 图标与文字按垂直中线对齐；按钮文字不换行。
- 所有页面共用同一套 8px 栅格与卡片 token，不允许「这页稍微不一样」。

## 6. 固定机位与截图协议

- 每关 `screenshots` 字段必须写 3 个：**开场（建立空间）/ 任务中（焦点与可读性）/ wow 瞬间（情绪）**；
- 机位 = 玩家可站立点 + 朝向 + 时间/天气 + FOV；由插件 `teleportPlayer` + 场景锁定时间实现；
- 截图判据（供人类/视觉复查）：①焦点是否第一眼可辨 ②前景/中景/背景是否分层 ③亮度对比是否足够 ④有无「空、脏、乱」区域 ⑤是否 MC 地道（不是浮空平台）。
- 汇报素材：每 Act 1 张主图 + 3 个 wow 帧；**再生成一张「溪木驿式」扁平插画地图**（关卡选择/报告封面用），这是对照方案最强的包装手法，成本低、收益高。

## 7. 与「对方方案」的取舍

- ✅ 抄：单地图/三场所密度、固定视线与镜头、调色统一、报告插画化地图、每关固定截图、目标可读性优先。
- ❌ 不抄：把所有任务压进一个村庄导致抽象覆盖变窄；我们用「同一片区域的多个场所 + 三幕时间变化」拿到他们的统一性，同时保留我们的宽度。
- 折中：Act I–II 的 8 个场景挤在村庄半径 300 格内，Act III 用村庄北侧峡谷 + 村下遗迹（同一世界，不需要换图）。

## 8. 实施安排

- **T1**：`sceneKit` 增加「美知道具」primitive（`decor` builder：灯列/旗列/花箱/烟/藤蔓），锁定 seed 与主地图区域；
- **T2**：Act I 美术 pass（灯河/麦田/村庄黄昏）——优先做 L1/L3/L4 三张可截图；
- **T3**：Act II/III 美术 pass（工坊/破晓/桥）+ 生成扁平插画地图；
- **T4 上午**：只修 demo 路径上的镜头与亮度，不再加新道具；
- 验收：每 Act ≥3 张达标截图 + 1 张插画地图 + demo 彩排时「画面能让人抬头」。
