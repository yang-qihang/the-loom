# 27 — 试符台（REPL）：一次试一句

> 状态：v1（D47 修正真实接线）｜负责人：Lead / Codex｜最后更新：2026-11-04
> 用户要求：支持 REPL，让玩家可以 experiment with some single instructions。
> 定位：世界观里的「试符台」——织者用来试一小句符文、看世界反应的矮桌；**不是关卡，不计星、不算失败**。
> 实施说明（2026-11-01 文档审计）：试符台已落地（`POST /api/repl` 等，见 `apps/engine/README.md`）；本文件设计目标仍适用。
> 上游：docs/20-quality-bar.md、docs/21-t1-contracts.md、docs/11 D47、docs/64

## 1. 体验

- 入口：地图墙底部「试符台」；工作台按 Esc 也可「去试一句」。
- 场景：灰岩村边的一张矮桌，旁边站着灰崽与艾拉；背景就是 L01 的小径。**真实模式连接当前关卡的真实灰崽**；动作会改变现场，不直接计星，不替代关卡代码要求。没有活跃世界时建立独立真实试符台；本地演示使用内存世界。
- 交互：一个输入框（等宽字体）+ 一个「试一句」按钮 + 历史列表；每次只执行**一行**。
- 反馈：世界变化（织偶动、灯亮）+ 一行结果（是值就显示值，是动作就显示「灰崽照做了」）+ 中文错误（哪里错、怎么改）。
- 不直接评分；随时「清空记录」。真实模式下「把现场恢复原样」会重置本关，UI 明示。

示例（玩家可以照着试）：
```
golem.say("你好，灰崽")
golem.moveTo(2, 6)
golem.place("lantern", 2, 14, 6)
golem.pos
```

## 2. 语义（v1 冻结）

| 项 | 规则 |
|---|---|
| 一次一行 | 只允许单条语句或单个表达式；空行忽略；多行不执行（提示「一次试一句」） |
| 自动 await | 与关卡一致：写操作自动等待完成再返回（Act I–II 的顺序门面） |
| 表达式 | 支持 `golem.pos`、`world.vars...`、数字/字符串/算术等；返回 JSON 安全值 |
| 世界持久 | 同一试符台会话内世界保持；「重置试符台」回到初始场景 |
| JS 变量 | v1 **不跨行保留**（一次一行，每行独立执行）；需要变量请用关卡编辑器。UI 明确写「一次一句，不记变量」 |
| 沙箱 | 与关卡同一套 worker+vm 沙箱、超时、只注入 `golem/world/console` |
| 评分 | REPL 不直接评分、不改最近学生源码；真实动作会改变当前世界，目标面板仍按世界真值更新 |
| 错误 | 中文人话；不出现堆栈/RPC/JSON；失败后可继续 |
| 安全 | 只在本地回环；与关卡同一 API 白名单（v1 只开放 `golem.*` 与 `world.vars` 只读） |

## 3. Engine API（在 docs/21 §3 追加）

| 方法 | 路径 | 请求/响应 |
|---|---|---|
| POST | `/api/repl` | `{ sessionId, line }` → `{ ok, kind: "value"|"action"|"error", display, log, error? }` |
| GET | `/api/repl/history?sessionId=` | `{ entries: [{line, kind, display, at}] }` |
| POST | `/api/repl/reset` | `{ sessionId }` → `{ ok }`（重建试符台场景） |

- Studio 创建时传 `{levelId, mode: "repl", live: true}`；Paper 复用同关卡真实会话，不重新 prepare/dispose。没有活跃世界时准备本关的真实 REPL；旧接口不传 live 时保持内存隔离兼容。
- 实现：session 调 `runner.runReplLine(port, line)`；表达式走「求值并返回值」，语句走「自动 await 执行」；错误翻译复用 `packages/errors`。

## 4. Studio UI（纯中文）

- 标题：**试符台**；副标题：「一次试一句。世界会照着做。」
- 输入框占位：「写一句，比如：让灰崽走到 2 号灯下」——不写英文 API；下面一行灰色小字提示可用写法（代码名用等宽）。
- 按钮：「试一句」「清空记录」「重置试符台」；快捷键：回车试一句。
- 历史：每条一行，左侧「你写的」/「灰崽」标签，右侧结果；错误用红色描边 + 中文说明，不用英文。
- 空状态：放一句示例，可一键填入（不是自动执行）。
- 无障碍：字号 ≥16px，结果不只靠颜色。

## 5. 验收

- [ ] 地图墙可进试符台；Esc 可去；返回不丢关卡进度；
- [ ] 4 条示例全部可执行；世界有真实反应（真实 MC / Mock 均可验）；
- [ ] 表达式返回可读值（`golem.pos` 显示坐标）；动作返回「灰崽照做了」；
- [ ] 错误中文可读；循环/普通表达式使用 3s 超时，单个真实 SDK 动作可等待 60s；
- [ ] 不直接评分；真实动作在原关卡快照可见，重置后本关世界回初始；
- [ ] UI 纯中文（docs/20 §3b）；标题按中线对齐（docs/20 §3b3）；
- [ ] Playwright 覆盖：进入试符台 → 执行一条 → 看到结果 → 重置。

## 6. 不做（v1）

- 跨行变量、函数定义、多行编辑（提示去关卡编辑器）；
- 在试符台里调用关卡评分/隐藏测试；
- 任意 Node/网络能力（沙箱限制不变）。
