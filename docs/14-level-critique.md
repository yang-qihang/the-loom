## 5. 动机 / wow / 玩家节拍 / 反模式 / 断言可靠性

**playerBeat ≤60s**：多数明确；**L05 的四次题名**无时长上限，极可能超 60 秒 → 改为「名字预填、玩家只确认」。L02 两次节拍、L06 交易 UI 也建议补时长声明。

**06 §6.3 反模式扫描**：0 关命中「只 toast 反馈」「提示贴完整代码」「只查无报错」「无隐藏测试」「10 步无关操作」「时长 <5/>30」。越级项（LAB-T 的 `assert`、L04 的下标）已由 D30/14b 处理。

## 7. 课程级结论

**7.1 PASS/FAIL**：PASS 3/13（L04、L08、L09）；FAIL 10/13。修复顺序按优先级：L06 → L07 → L05（P0/P1 核心）→ L01 → L02 → L03 → L10/EP/LAB-R/LAB-T（P2）→ L08/L09 的 contract 收尾（14b）。

1. **L06 按 D5-A8 拆两 phase 并缩验收**——P1 唯一「教学裁决未落地」的关卡，不改则报告里「ADT 教学」说法不成立。
