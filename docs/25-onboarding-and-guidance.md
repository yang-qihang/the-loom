# 25 — 引导与背景叙事规格（Onboarding & Guidance）

> 状态：v1 冻结（补充 docs/20 §3b）｜负责人：Lead｜最后更新：2026-10-31
> 用户要求：**引导不能省。** 只给一点点引导、玩家连故事背景都不知道，才是真的奇怪。
> 原则：引导要「够清楚」，不是「够多字」；用短句、分屏、可回看，禁止一屏文字墙。

---

## 1. 玩家在任何时刻都必须能回答五个问题

1. **我是谁？** —— 捡到织机碎片的学徒，手上有「织者之印」。
2. **这个世界怎么了？** —— 大织机断线，散线让东西忘记自己该做什么。
3. **这只织偶是什么？** —— 织机织出的无魂工匠，只会照字面执行；不是宠物，也不是魔法仆从。
4. **我现在要做什么？** —— 目标面板的三条以内，用中文说清楚「做什么、做到什么程度」。
5. **做错了会怎样？** —— 不惩罚，可以重来；错在哪里、看哪一行。

任何关卡/界面只要有一问答不上，就是引导缺口，必须补。

## 2. 四层引导（全部必须有）

| 层 | 时机 | 内容 | 形式 | 预算 |
|---|---|---|---|---|
| **序章** | 首次进入 | 灰岩村、断纬之夜、艾拉、织偶、三枚织核 | 分屏对话 + 环境演出（可跳过，但默认播；看完解锁「旅途手记」） | 6–8 屏；总字数 ≤900；每屏 ≤2 句 |
| **幕开场** | 每幕进入 | 这一幕世界变成什么样、这三关要学会什么 | 2–3 屏 + 镜头（玩家站定点） | 每幕 ≤300 字 |
| **关开场** | 每关进入 | 世界状态一句 / 任务一句 / 为什么是你一句 | 3 句对话框 + 目标面板 | 每关 ≤180 字 |
| **即时引导** | 卡点/错误 | 教练短句、三级提示、错误翻译 | 侧栏 + 世界内动作 | 单条 ≤60 字 |

**可回看**：Esc 打开「旅途手记」：世界背景 / 已解锁名词 / 当前目标 / 上一关发生了什么。**任何时候都能重看序章与名词解释。**

## 3. 每关开场模板（3 句，必须写满）

1. **世界状态**（发生了什么，为什么现在要做）：例：「小径上的灯又灭了。今晚村里有人要回来。」
2. **任务**（做什么、做到什么程度）：例：「先点亮 1 到 3 号灯，再走到 4 号灯下。」
3. **为什么是你 / 规则提示**：例：「最后那盏要你亲手点。活人的手，织偶替不了。」

> 禁止只写第 2 句就开局。**没有 1 和 3，玩家就不知道故事。**

## 4. 序章脚本（6 屏，正式文案以 docs/22 v2 为准）

| 屏 | 画面 | 台词（每屏 ≤2 句） |
|---|---|---|
| 1 | 黄昏的灰岩村，风车停转，灯全灭 | 艾拉：「你来得正好。村子已经三天没亮过灯了。」 |
| 2 | 田里成熟的麦子没人收，鸡在空窝边打转 | 艾拉：「不是没人干活。是干活的东西，忘了自己该做什么。」 |
| 3 | 一只倒地的织偶，胸口织机碎片发暗 | 艾拉：「它叫灰崽。织机织出来的工匠，没有心思，只会照字面做事。」 |
| 4 | 村底大织机的轮廓在暮色里 | 艾拉：「那一夜，大织机的纬线断了。散线从底下漫出来，碰到的东西就慢慢忘了自己。」 |
| 5 | 艾拉把一片发亮的碎片放进你手心 | 艾拉：「你手上的印，能写符文。写清楚了，世界就照着做。」 |
| 6 | 第一期目标面板亮起：三盏灯、艾拉身边 | 艾拉：「先把这条路点亮。我们从第一缕光开始。」 |

要求：序章每屏有环境音与一个可见变化（灯灭→碎片亮→目标亮），不只放文字；可跳过，跳过也算看过（写进存档），但手记里随时能回看。

## 5. 文本预算（修订版，覆盖 docs/06 旧值）

| 项 | 旧 | 新 |
|---|---|---|
| 教练单条 | ≤45 字 | **≤60 字**（仍禁止长段落） |
| 每关对话条数 | ≤10 | **≤14**（含关开场 3 句） |
| 每关总叙事字数 | 未定 | **≤700 字**（序章/幕开场另计；宁可多写一句完整话，不要压缩到指代不清） |
| 序章总字数 | 未定 | ≤900 字（6–8 屏） |
| 每幕开场 | 未定 | ≤300 字 |
| 目标 | ≤3 条、每条 ≤20 字 | 不变 |
| 提示 | 3 级、每级 ≤45 字 | **≤60 字**（仍三级、不直接给完整答案） |

**严禁**：一屏超过 3 句、连续两屏纯说明、把设定塞进加载提示、用旁白一次讲完世界观。**必须**：先给画面/动作，再给一句解释；名词首现给一句人话（docs/23 §8）。

## 6. 引导验收（机器 + agent 盲读）

- **机器**：validator 检查每关有 `narrative.opening` 3 句、`narrative.whyYou`、`narrative.worldState`；序章/幕开场存在；教练条数/字数不超预算。
- **agent 盲读**：只给「序章 + 当前关开场 + 目标面板」，让 5 个 fresh agent 回答 §1 的五个问题；任一问题有 ≥2 个 agent 答不上，判 FAIL，补引导。
- **可回看**：Esc 手记能在一屏内找到「世界怎么了 / 我在哪 / 现在做什么」；不允许只有开始菜单能看。
- **不通过**：不允许进入下一关的验收；引导是玩法的一部分，不是装饰。

## 7. 常见错误（一律打回）

- 只有「点灯」「种田」一句任务，没有世界状态与「为什么是你」。
- 名词先出现、解释后置（或永远不解释）。
- 用一屏 100+ 字讲设定；玩家直接跳过。
- 把教程做成「点下一步」十连击，没有可玩动作。
- 跳过序章后无法再回看，导致中段剧情断裂。
- UI 里出现「玩家/用户/您」或英文标签（见 docs/20 §3b）。

## 7b. MC 操作帮助：只在需要玩家动手时出现

- **默认假设玩家零 Minecraft 知识**：不知道 WASD、右键、准星、窗口切换，都是正常的。
- **不要提前教**：序章/编辑器阶段不介绍 Minecraft 操作；只在「轮到你」卡片出现时展开一页「第一次玩 Minecraft？」说明。
- 说明必须包含：切窗口 → W/A/S/D 走路 + 鼠标转视角 → 走到目标下、准星对准 → 右键点亮；键名可用 W/A/S/D（按键专名），其余叙述全中文。
- **弄乱可恢复**：帮助里明确「走错/弄乱方块/卡住 → 按『重置本关』恢复，代码不会丢」，并提供一键重置按钮。
- 该帮助只在玩家节拍阶段出现，可折叠；不强迫阅读。L03 敲钟等后续 MC 操作复用同一组件，按关卡替换目标句。
